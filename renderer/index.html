      Przegląd bezpieczeństwa

      Sprawdzenie wycieków haseł Porównuje hasła z bazą ponad 900 mln haseł z wycieków (Have I Been Pwned). Hasła nie opuszczają komputera – wysyłane jest tylko 5 pierwszych znaków ich skrótu SHA-1, a serwis zwraca setki pasujących skrótów, wśród których program sam szuka dopasowania.

        Microsoft 365 – konto administratora

        Synchronizacja działa tylko w jedną stronę: program pobiera listę użytkowników, dane kontaktowe i przypisane licencje. Niczego nie wysyła ani nie zmienia w Microsoft 365 – prosi wyłącznie o uprawnienia do odczytu (User.Read.All, Organization.Read.All). Hasła, uwagi i własne pola zostają tylko w skarbcu.

        Logujesz się, aby włączyć zmianę haseł. Program poprosi dodatkowo o uprawnienie User-PasswordProfile.ReadWrite.All (tylko ustawianie haseł). Zaloguj się kontem administratora globalnego lub administratora uwierzytelniania uprzywilejowanego i wyraź zgodę w imieniu organizacji. Hasła zmieniane są wyłącznie po Twoim poleceniu w oknie „Zmień hasła”, dla wskazanych kont.

        Własna aplikacja w Entra ID (opcjonalnie)

        Domyślnie logowanie odbywa się przez aplikację Microsoftu „Microsoft Graph Command Line Tools”. Jeśli Twoja organizacja jej nie dopuszcza, zarejestruj własną: Entra ID → Rejestracje aplikacji → Nowa rejestracja; Uwierzytelnianie → „Zezwalaj na przepływy klienta publicznego”: Tak; Uprawnienia interfejsu API → Microsoft Graph → delegowane: User.Read.All, Organization.Read.All (do zmiany haseł także User-PasswordProfile.ReadWrite.All) → Udziel zgody administratora.
